# Decisions — the state of play

Read this first. Each entry: what, why, what it rules out. A decision is **superseded**, never silently edited: mark it
`SUPERSEDED by Dnn` and add the new one.

Status key: **LOCKED** (decided; those marked *My call* were delegated to Claude by the designer and stay open to their veto) ·
**PROPOSED** (Claude's recommendation, awaiting a yes) · **INHERITED** (carried from Little Shinobi; status shown) · **OPEN**.

**Current phase: 0 — Foundations. Code only for the feel ladder (D078); nothing else is coded.** The hero is Kaname (`hero.md`). The story has a first complete
canon (`story.md`): six chapters, the founding secret, three clans, hell, the ending. A first sketch of how the world interconnects
is in `world-sketch.md`. Still to do in Phase 0: the core play in detail (0.4) and the look, sound and tech (0.5). Gates signed: none.
**2026-10-18: the designer's documentation package arrived (D119)** in `docs/Kaname_Documentation/`: the Game Design Bible is the updated
narrative direction, but it does not override what is built and tested; its conflicts with this log are listed under *The documentation
package: conflicts*. The Unity port is in the **U4 polish milestone** (D125): look-only work on the sword, the slash and the pogo.
